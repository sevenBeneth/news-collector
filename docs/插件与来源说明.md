# 插件来源与编写比例说明

> 作业要求：引入模板/插件需说明来源，并说明自己编写的比例。本文档如实记录本项目用到的第三方资产与自研部分。

## 一、前端（web/，uni-app）

### 2. 自研部分（前端）

| 自研内容 | 说明 |
|---|---|
| `components/banner-swiper` | 首页轮播组件（swiper + 指示器 + 点击事件） |
| `components/ai-summary-card` | AI 摘要卡片（徽标 + 摘要 + 关键词标签 + 免责提示） |
| `components/keyword-tags` | 关键词标签组（逗号串/数组自适应） |

**前端自研比例（估）**：约 **35%**（组件与页面逻辑自研），其余 **65%** 为模板与第三方组件资产（其中部分页面逻辑在模板基础上调整字段）。

## 二、后端（api-server/，Spring Boot）

| 依赖 | 用途 | 来源 |
|---|---|---|
| Spring Boot 2.1.8 / Spring MVC | Web 框架 | 官方 |
| MyBatis + tk.mybatis 通用 Mapper | ORM | 官方 / MyBatis 生态 |
| PageHelper | 物理分页 | 官方 |
| MySQL Connector/J 8.0.21 | 数据库驱动 | 官方 |
| fastjson | JSON 序列化 | 阿里 |
| java-jwt（auth0） | 无状态登录态 | 官方 |
| hutool-core、commons-lang3/codec/io | 工具类 | 官方 |
| springfox-swagger2 / swagger-ui | 接口文档 | 官方 |
| Lombok | 样板代码 | 官方 |

**继承自原 CMS 后端并保留的代码**：统一返回体 `BasicResult`、全局异常处理 `BasicExceptionAdvice`、响应包装 `JsonResponseBodyAdvice`、`JWTUtil`、`MD5Utils`（加盐 MD5）、`SensitiveWordFilter`（敏感词，依赖 `words.txt`）、`Swagger2Config`。

**本次移除**：Druid 连接池与监控、Redis（登录态改为无状态 JWT）、微信小程序 SDK（`weixin-java-miniapp`）、`spring-boot-starter-data-rest`、jjwt。

**本次重写/新增（自研）**：包结构（`com.wuhu.news`）、9 个实体与 Mapper、新闻业务服务、DeepSeek 摘要服务、采集入库服务、管理端服务、三个控制器、跨域过滤器、异步线程池、启动初始化。

**后端自研比例（估）**：约 **85%** 为本次编写（含重写与新增），约 **15%** 沿用原项目工具与统一返回/异常处理。

## 三、采集器（crawler/，Python）

| 依赖 | 用途 |
|---|---|
| requests | HTTP 请求 |
| beautifulsoup4 / lxml | HTML 解析 |
| （参考项目其余依赖未使用：selenium / pandas / jieba / matplotlib / tenacity） | —— |

**参考的开源项目**：`BaiduNews_Crawler`（Selenium + BeautifulSoup 定向采集百度新闻 + CSV 去重 + tenacity 重试）。本项目**复用其思路**（无头浏览器兜底、随机间隔、重试、按链接去重、编码探测），但**技术路线改为 requests + BeautifulSoup 直连静态列表页**，并新增：多源适配器、正文抽取、关键词过滤、编码归一、HTTP 入库、采集日志。

**采集器自研比例（估）**：约 **70%** 为本次编写，约 **30%** 复用参考项目的模式与工具函数。

---

## 四、管理端（内置静态页）

`api-server/src/main/resources/static/admin/index.html`：**单文件、零第三方依赖**（原生 HTML + 内联 CSS + 原生 ES6，无 CDN、无 UI 库、无图表库），全部自研，**自研比例 100%**。

---

## 五、第三方服务

| 服务 | 用途 | 计费 |
|---|---|---|
| **DeepSeek API**（`deepseek-chat`） | 新闻自动摘要、关键词抽取、频道归类 | 按 token 计费，实测单篇约 300 tokens |

AI 部分的**提示词设计、JSON 结构化约束、结果解析、降级策略、token 计量、异步调度**均为自研。

## 六、AI 辅助编程说明

本项目开发过程中使用了 AI 编程助手辅助完成部分代码与文档（含：实体/Mapper/Controller 骨架生成、Python 采集器实现、管理端单文件页面实现、文档起草）。所有 AI 生成内容均经过人工审查、编译验证与接口实测（后端 `mvn package` 通过；管理端页面经无头浏览器 63 项断言、1366×768 布局 23 项检查；接口经真实 HTTP 调用与数据库核对）。
